# Dancing Queen 独立站部署 & 修改指南
========================================

## 🚀 部署到 Vercel（上线独立站）

### 方法一：网页上传（最简单）
1. 打开 https://vercel.com 并登录（用 GitHub 账号一键登录）
2. 点击 "Add New..." → "Project"
3. 选择 "Import" 方式
4. 上传 `dancing-queen-v3.zip` 文件
5. 等待部署完成，你会得到一个域名如：`dancing-queen.vercel.app`
6. 在 Vercel Dashboard 绑定你的自定义域名

### 方法二：使用 Vercel CLI（如果你有 VPN）
```bash
# 安装 Vercel
npm install -g vercel

# 进入项目目录
cd "C:\Users\Admin1\Desktop\新建文件夹 (2)"

# 登录
vercel login

# 部署
vercel --prod
```

## ✏️ 如何修改网站内容（上线后）

### 修改价格
1. 打开对应 HTML 文件（如 `incense.html`）
2. 搜索价格如 `$48`，直接改成 `$50`
3. 保存，重新打包上传到 Vercel

### 修改产品描述
1. 打开 `product-detail.html`
2. 找到对应的产品对象（如 `rose-a`）
3. 修改 `desc`、`materials` 等字段
4. 保存，重新打包上传

### 添加新产品
1. 把产品图片放到 `images/incense/` 文件夹
2. 复制一个产品卡片，修改名称和图片路径
3. 在 `product-detail.html` 的 `products` 对象里添加新数据
4. 保存，重新打包上传

### 添加微信/支付宝收款码
1. 把二维码图片放到 `images/payments/` 文件夹
2. 打开 `product-detail.html`
3. 搜索 `qr-placeholder`，把占位文字换成：
   ```html
   <img src="images/payments/wechat-pay.jpg" alt="WeChat Pay" style="width:100%;height:100%;object-fit:contain;">
   ```
4. 保存，重新打包上传

## 📤 重新打包步骤

1. 删除所有 `.xlsx` 文件（避免上传过大）
2. 右键文件夹 → 发送到 → 压缩文件夹
3. 重命名为 `dancing-queen.zip`
4. 打开 https://vercel.com/dashboard
5. 点击你的项目 → "Redeploy" → 上传新 ZIP
6. 等待约 1-2 分钟，网站自动更新

---

## 🔗 绑定自定义域名

1. 登录 Vercel Dashboard
2. 进入你的项目 → Settings → Domains
3. 输入你的域名（如 `www.dancingqueen.com`）
4. 按提示修改 DNS 记录（添加 CNAME 或 A 记录）
5. 等待 DNS 生效（通常 10 分钟 - 24 小时）
