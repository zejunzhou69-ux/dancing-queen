## 🚀 手动部署步骤（推荐）

### 步骤 1: 打开 Vercel
1. 确保已在浏览器打开: https://vercel.com/new?teamSlug=zejun&building=static-site
2. 确认已登录 GitHub 账号

### 步骤 2: 上传文件
1. 点击页面上的 **"Upload"** 按钮
2. 在文件选择对话框中，导航到:
   C:\Users\Admin1\Desktop\新建文件夹 (2)\
3. 选择文件: **dancing-queen-deploy.zip**
4. 点击 **"打开"** 或 **"Upload"**

### 步骤 3: 配置项目
| 设置项 | 值 |
|--------|-----|
| Project Name | dancing-queen |
| Framework Preset | **Other** |
| Root Directory | / |
| Build Command | *(留空)* |
| Output Directory | . |

### 步骤 4: 完成部署
1. 点击 **"Deploy"** 按钮
2. 等待 1-2 分钟
3. 部署成功后会显示访问链接:
   https://dancing-queen.vercel.app

## 🔗 绑定自定义域名（可选）

1. 进入 Vercel Dashboard
2. 点击你的项目 → Settings → Domains
3. 输入你的域名（如 www.dancingqueen.com）
4. 按提示修改 DNS 记录:
   - 添加 CNAME: www → cname.vercel-dns.com
5. 等待 DNS 生效（通常 10分钟-24小时）
